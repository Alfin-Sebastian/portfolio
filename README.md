## 🌟 Key Highlights

- **Interactive Architecture Simulators**:
  - **SwipeRide (MERN Stack)**: A 4-stage ride lifecycle simulation (*Request ➔ Acceptance ➔ Trip ➔ Completion*) featuring an interactive emergency SOS audio alert demonstration.
  - **UrbanServe (PHP & MySQL)**: A 3-role local services dashboard exploring Customer, Provider, and Administrator portal workflows.
- **Interactive Developer Console**: An in-browser interactive terminal (`~/portfolio`) supporting commands like `skills`, `projects`, `certs`, `swiperide`, and `contact`.
- **Dynamic Cloud CMS**: Powered by Google Firebase Realtime Database for seamless real-time data synchronization.
- **Verified Industry Credentials**: Showcasing verified accreditations from Anthropic (Claude 101, AI Fluency), Forage (Tata, Deloitte), and EF SET (C2 English Proficiency).
- **Responsive Cybernetic Aesthetic**: Particle constellation canvas background, real-time Kerala clock (IST), and mobile-first responsive layout.

## 🚀 Local Development Setup

To run this portfolio locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/Alfin-Sebastian/portfolio.git

# 2. Navigate into the directory
cd portfolio

# 3. Install dependencies
npm install

# 4. Start the local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

To create an optimized production build:

```bash
npm run build
```
