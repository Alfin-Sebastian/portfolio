## 🚀 Quick Start Guide

### 1. Navigate to the project directory:
```bash
cd "C:\Users\Alan\.gemini\antigravity\scratch\alfin-portfolio"
```

### 2. Start the local development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the site live.

### 3. Build for Production:
```bash
npm run build
```
Creates an optimized, minified bundle in the `dist/` folder ready for zero-config deployment.

### 4. Preview the Production Build:
```bash
npm run preview
```

---

## 🌐 Deploy to Vercel / Netlify / GitHub Pages

- **Vercel**: Import the folder or GitHub repo, set framework preset to `Vite`, and click Deploy.
- **Netlify**: Drag and drop the `dist/` folder into Netlify Drop, or connect your GitHub repository with build command `npm run build` and publish directory `dist`.
- **GitHub Pages**: Add `"base": "/<repo-name>/"` to `vite.config.js` and push `dist` to `gh-pages` branch.
